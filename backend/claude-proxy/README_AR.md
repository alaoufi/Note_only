# وسيط مساعد الذكاء الاصطناعي (Claude Proxy)

خادم وسيط صغير يبقي **مفتاح Anthropic سرًّا** بعيدًا عن أجهزة المستخدمين، كي
يعمل مساعد الملاحظات لكل المستخدمين دون أن يُدخل أحدهم مفتاحًا.

المسار: `worker.js` (Cloudflare Worker جاهز للنشر).

## لماذا وسيط؟

- تطبيق الجوال لا يُمكن أن يحمل مفتاح المزوّد بأمان (يمكن استخراجه من الحزمة).
- الوسيط يحتفظ بالمفتاح على الخادم، ويحقنه في كل طلب، ويعيد ردّ Claude كما هو.
- التطبيق يرسل **نفس بنية رسائل Anthropic**، فلا حاجة لأي منطق إضافيّ في الوسيط.

## النشر على Cloudflare Workers (مجّانيّ للبدء)

1. سجّل الدخول إلى <https://dash.cloudflare.com> ← **Workers & Pages** ← **Create Worker**.
2. الصق محتوى `worker.js` بالكامل، ثم **Deploy**.
3. **Settings ← Variables and Secrets**:
   - أضِف سرًّا: `ANTHROPIC_API_KEY` = مفتاحك `sk-ant-…` (اختر **Encrypt**).
   - (موصى به) أضِف سرًّا: `APP_SHARED_SECRET` = نصّ عشوائيّ طويل.
4. انسخ رابط الـ Worker، مثل: `https://claude-proxy.<حسابك>.workers.dev`.

## ربط التطبيق

طريقتان (تكفي إحداهما):

- **وقت البناء** (الأنسب للنشر — يعمل لكل المستخدمين تلقائيًّا):

  ```bash
  flutter build appbundle \
    --dart-define=STORE_BILLING=true \
    --dart-define=AI_ENDPOINT=https://claude-proxy.<حسابك>.workers.dev \
    --dart-define=AI_PROXY_SECRET=<نفس APP_SHARED_SECRET>
  ```

- **من داخل التطبيق**: الإعدادات ← «مساعد الذكاء الاصطناعي» ← إعداد المساعد ←
  ضع «رابط الخدمة» و«سرّ التطبيق».

> إعداد المستخدم على الجهاز **يتجاوز** قيم البناء إن وُجد.

## الأمان

- الوسيط يقبل `POST` فقط، ويتحقّق من `APP_SHARED_SECRET` إن ضُبط.
- يحدّ حجم الطلب و`max_tokens`.
- فعّل **Rate Limiting** من لوحة Cloudflare (WAF → Rate limiting rules) لمنع الإساءة.
- لا تُشارك `ANTHROPIC_API_KEY` أبدًا، ولا تضعه في التطبيق أو في مستودع عامّ.

## بديل: مفتاح خاصّ لكل مستخدم (BYOK)

للاستخدام الشخصيّ دون نشر وسيط: الإعدادات ← إعداد المساعد ← ألصق مفتاح Anthropic
الخاصّ بك. يُخزَّن في التخزين الآمن على الجهاز فقط ويُرسل مباشرةً إلى الـ API.
