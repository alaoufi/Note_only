## المسار المقترَح (تسلسل عمليّ)

1. **الآن (أساس):** CI ✅ + تثبيت الحزم ✅ + سجلّ الأعطال (#3) + اختبارات حرجة (#4).
2. **التالي (تجربة المستخدم):** جولة الترحيب (#8) + شاشات فارغة (#9) + القوالب (#11).
3. **ثم (البيانات والإخراج):** التصدير الجماعي (#13) + تصدير الكلّ (#14) + اختبار الاستعادة (#7).
4. **لاحقًا (توسّع):** البحث المتقدّم (#10) + iOS (#21) أو المزامنة (#23) حسب الأولوية.

> كل بند يُنفَّذ في فرع، يمرّ عبر CI (تحليل+اختبار+بناء)، ويُدمج فقط عند الخُضرة —
> فيبقى أندرويد مستقرًّا دائمًا. مبدأ ثابت: **إضافة لا تكسر، ورقم نسخة يرتفع،
> وقاعدة تُرحَّل لا تُمحى** (انظر `docs/دليل_التحديث_والحفاظ_على_البيانات.md`).
