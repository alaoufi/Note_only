# دليل نسخة ويندوز (Windows Desktop)

هُيّئ المشروع لمنصّة ويندوز (وُلّد مجلد `windows/` وفُعّل `enable-windows-desktop`).
هذا الدليل يشرح ما تبقّى لجعله يعمل فعليًّا على ويندوز، لأنّ عدّة إضافات تعمل على
أندرويد فقط.

> **يجب البناء على جهاز Windows** مثبَّت عليه **Visual Studio 2022** (حِمل «Desktop
> development with C++»). لا يمكن بناء ويندوز من لينكس/ماك.

---

## 1) حالة الإضافات على ويندوز

### مدعومة (تعمل مباشرة)
`audioplayers، dynamic_color، file_selector، flutter_secure_storage، flutter_timezone،
local_auth، permission_handler، record، share_plus، speech_to_text، url_launcher،
path_provider`.

### غير مدعومة على ويندوز (تحتاج معالجة)
| الإضافة | الأثر | الحلّ المقترح |
|---|---|---|
| **`sqflite_sqlcipher`** | ❌ قاعدة البيانات لا تفتح — التطبيق لا يخزّن شيئًا | **حاجز أساسيّ** — انظر §2 |
| **`android_id`** | ❌ رقم جهاز UNI3 لا يُشتق (التفعيل) | معرّف بديل على ويندوز — انظر §3 |
| `flutter_local_notifications` | تذكيرات لا تُطلق | بديل إشعارات ويندوز أو تعطيل التذكير على المنصّة |
| `in_app_purchase` | لا اشتراكات | نسخة ويندوز تستخدم بوابة التفعيل (kStoreBilling=false) افتراضيًّا — لا يلزم |
| `in_app_review`, `home_widget` | لا تقييم/ودجت | حماية بفحص المنصّة (تجاهُل بلا خطأ) |
| `image_picker` | اختيار الصور | استخدم `file_selector` (مدعوم) على ويندوز |
| `google_sign_in` | مزامنة Drive | عطّلها على ويندوز أو استخدم تدفّق OAuth سطح مكتب |

معظم هذه الإضافات ترمي `MissingPluginException` عند الاستدعاء على منصّة غير مدعومة؛
التطبيق يلتقط أخطاء التهيئة في `startupErrors` فلا ينهار، لكن الميزة تتعطّل.
احرِس النداءات الحسّاسة بـ `if (Platform.isAndroid) …` أو `defaultTargetPlatform`.

## 2) قاعدة البيانات على ويندوز (الحاجز الأساسيّ)

`sqflite_sqlcipher` يعتمد قنوات منصّة أندرويد/iOS. على سطح المكتب استخدم **FFI**:

**الخيار الموصى به (يحافظ على التشفير):**
- أضِف `sqflite_common_ffi` + `sqlcipher_flutter_libs` (توفّر مكتبة sqlite مبنيّة مع
  SQLCipher لسطح المكتب).
- عند الإقلاع على ويندوز اضبط مصنع قاعدة البيانات إلى FFI قبل أي فتح:
  ```dart
  import 'dart:io' show Platform;
  import 'dart:ffi';
  import 'package:sqflite_common_ffi/sqflite_ffi.dart';
  import 'package:sqlcipher_flutter_libs/sqlcipher_flutter_libs.dart';

  // في main() قبل تهيئة القاعدة:
  if (Platform.isWindows) {
    open.overrideFor(OperatingSystem.windows, openCipherOnWindows);
    sqfliteFfiInit();
    databaseFactory = databaseFactoryFfi; // ويستخدم PRAGMA key كالمعتاد
  }
  ```
- في `app_database.dart` استخدم نفس `openDatabase(..., password: key)` — مصنع FFI
  مع sqlcipher يقبل `password`. اختبِر أنّ الترحيل والفتح يعملان.

**خيار أبسط (بلا تشفير — غير مُوصى به):** `sqflite_common_ffi` وحده مع تجاهل المفتاح.
يفقد تشفير قاعدة البيانات — لا تستخدمه لبيانات حسّاسة.

> هذه الخطوة **تتطلّب اختبارًا على ويندوز**. لم تُطبَّق في الكود كي لا تُزعزع بناء
> أندرويد المستقرّ.

## 3) رقم جهاز التفعيل (UNI3) على ويندوز

`android_id` غير متاح. استبدل مصدر `ANDROID_ID` بمعرّف ويندوز ثابت:
- استخدم `device_info_plus` (مدعوم): `WindowsDeviceInfo.deviceId` (معرّف الجهاز)،
  أو معرّف التثبيت من التسجيل/`MachineGuid`.
- أبقِ **نفس معادلة UNI3**: `Base32(SHA-256(APP_ID + ":" + <معرّف الجهاز>)[0:10])`.
- عدّل `license_service.dart` ليختار المعرّف حسب المنصّة (Android → ANDROID_ID،
  Windows → معرّف ويندوز). المولّد (keygen) يبقى كما هو.

## 4) خطوات البناء على ويندوز

```powershell
# على جهاز Windows فيه Flutter + Visual Studio 2022 (C++ desktop)
flutter config --enable-windows-desktop
flutter pub get
flutter run -d windows            # تشغيل للتطوير
flutter build windows --release   # ناتج: build\windows\x64\runner\Release\
```
الناتج مجلد فيه `mudhakkarati.exe` وDLLات. للتوزيع: احزم المجلد كاملًا (أو أنشئ
مثبِّتًا عبر MSIX: حزمة `msix`، أو Inno Setup).

### تغليف MSIX (اختياريّ)
```yaml
# في pubspec.yaml
dev_dependencies:
  msix: ^3.16.0
```
```powershell
dart run msix:create
```

## 5) قائمة عمل مختصرة للمنفِّذ

1. [ ] بناء أوّليّ على ويندوز لرصد الأخطاء الفعلية.
2. [ ] تكييف قاعدة البيانات (FFI + SQLCipher) — §2. **إلزاميّ.**
3. [ ] معرّف جهاز ويندوز للتفعيل — §3.
4. [ ] حراسة النداءات غير المدعومة بـ `Platform.isAndroid`.
5. [ ] استبدال `image_picker` بـ `file_selector` على سطح المكتب.
6. [ ] قرار المزامنة/الإشعارات (تعطيل أو بديل ويندوز).
7. [ ] أيقونة وتوقيع تطبيق ويندوز + مثبِّت (MSIX/Inno).

> **الخلاصة:** الهيكل جاهز، لكن التشغيل الفعليّ يتطلّب تكييف طبقة قاعدة البيانات
> ومعرّف الجهاز والاختبار على ويندوز — كلّها تُنجَز وتُختبر على جهاز Windows.
