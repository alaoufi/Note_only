# دليل المطوّر الشامل — تطبيق «مذكراتي / ملاحظات»

مرجع كامل وحديث لبناء المشروع وتطويره ونشره. يغطّي البنية، وقاعدة البيانات،
والتفعيل (UNI3)، والاشتراكات (Google Play)، ومساعد الذكاء الاصطناعي، والأسرار.

> **آخِر تحديث:** الإصدار `1.8.0+49` — إصدار مخطّط قاعدة البيانات `21`.

---

| اسم العرض | ملاحظات / مذكراتي |

## 2) الحزمة التقنية (Tech Stack)

- **الإطار:** Flutter + Dart، إدارة حالة عبر `provider`.
- **قاعدة البيانات:** `sqflite_sqlcipher` (SQLCipher) — مفتاح في التخزين الآمن.
- **النصّ الغنيّ:** `flutter_quill` (يُخزَّن Delta JSON في `notes.content`).
- **الأمان:** `flutter_secure_storage` (Keystore)، `local_auth` (بصمة)، `encrypt`/`crypto`.
- **الوسائط:** `image_picker`، `record`، `audioplayers`، `speech_to_text`، `signature`، `pdf`.
- **المزامنة:** `google_sign_in` + `googleapis` (Google Drive، تشفير طرف-لطرف).
- **الاشتراكات:** `in_app_purchase` (Google Play Billing) + `in_app_review`.
- **مساعد الذكاء:** `http` (Claude API عبر HTTP خام — لا توجد حزمة Dart رسمية).
- **أخرى:** `share_plus`، `url_launcher`، `home_widget`، `flutter_local_notifications`،
  `timezone`، `hijri`، `device_info_plus`، `android_id`.

```
lib/

├─ features/                 # كل ميزة في مجلد
│  ├─ home/  editor/  search/  categories/  tags/  trash/  favorites/
│  ├─ security/              # بوابة التفعيل (UNI3) + القفل
│  ├─ subscription/          # الاشتراكات + التجربة + بوابة المتجر
│  ├─ ai/                    # مساعد الذكاء الاصطناعي (الورقة + الإعدادات)
```

## 4) إعداد البيئة والبناء

### المتطلبات
- Flutter `>=3.22` (اختُبر على 3.44.8) + Android SDK (platform-36، build-tools 36).
- JDK 17. مفتاح التوقيع `android/app/alaoufi-release.jks` (مضمَّن في المستودع).

### أوامر أساسية
```bash
flutter pub get
flutter analyze          # يجب أن يكون بلا أخطاء
flutter test             # كل الاختبارات تنجح
```

### بناء نسخة خارج المتجر (تفعيل UNI3)
النسخة الافتراضية (`kStoreBilling=false`) تعرض **بوابة تفعيل UNI3**:
```bash
flutter build apk --release
# أو أصغر حجمًا لجهاز محدّد:
flutter build apk --release --target-platform android-arm64
```

### بناء نسخة Google Play (اشتراكات + تجربة ١٠ أيام)
تُفعَّل ميزات المتجر عبر `--dart-define=STORE_BILLING=true`:
```bash
flutter build appbundle --release --dart-define=STORE_BILLING=true
```

### تفعيل مساعد الذكاء الاصطناعي للجميع وقت البناء (اختياريّ)
لتضمين رابط الوسيط فيعمل المساعد دون إعداد من المستخدم:
```bash
flutter build appbundle --release \
  --dart-define=STORE_BILLING=true \
  --dart-define=AI_ENDPOINT=https://your-worker.workers.dev \
  --dart-define=AI_PROXY_SECRET=<السرّ المشترك>
```

### مفاتيح `--dart-define` المدعومة
| المفتاح | الافتراضي | الأثر |
|---|---|---|
| `STORE_BILLING` | `false` | `true` ⇒ بوابة الاشتراك بدل بوابة التفعيل |
| `AI_ENDPOINT` | `''` | رابط وسيط Claude المضمَّن (يعمل المساعد للجميع) |
| `AI_PROXY_SECRET` | `''` | سرّ مشترك يُرسَل للوسيط بترويسة `x-app-secret` |

> إعداد المستخدم على الجهاز (شاشة إعداد المساعد) **يتجاوز** قيم البناء.

### التوقيع
معرَّف داخل `android/app/build.gradle.kts` (مشروع شخصيّ، توقيع ثابت ليُثبَّت
التحديث فوق السابق). لِنشر Google Play استخدم **App Signing** من Play Console.

## 5) قاعدة البيانات

- **الملف:** `mudhakkarati.db` في مجلد مستندات التطبيق، **مشفّر بالكامل** (SQLCipher).
- **المفتاح:** يُنشأ عشوائيًّا ويُحفظ في التخزين الآمن (`db_key.dart`) — لا يغادر الجهاز.
- **الإصدار:** `_dbVersion = 21`. الإنشاء عبر `_onCreate`، والترقية عبر `_onUpgrade`
  (سلسلة `ALTER TABLE`/جداول — بلا فقد بيانات). ترحيل تلقائيّ آمن من قاعدة نصّية
  قديمة إلى مشفّرة (`_migratePlainToEncrypted` مع تحقّق من تطابق عدد الصفوف).
- **المخطّط الكامل:** `docs/schema.sql` (بنية v21) + `docs/schema-reference.db`
  (قاعدة مرجعيّة غير مشفّرة للاطّلاع). التفاصيل جدولًا بجدول: `docs/DATABASE.md`.
- **الجداول:** `categories، notes، checklist_items، tags، note_tags، reminders،
  info_entries، med_doses، reminder_log`.

لإعادة توليد القاعدة المرجعية:
```bash
sqlite3 docs/schema-reference.db < docs/schema.sql
# أو بلا أداة sqlite3:
python3 -c "import sqlite3;c=sqlite3.connect('docs/schema-reference.db');\
c.executescript(open('docs/schema.sql',encoding='utf-8').read())"
```

> **لا يُخزَّن في القاعدة:** إعداد مساعد الذكاء (تخزين آمن)، وحالة الاشتراك/التجربة
> وتفضيلات الواجهة (`SharedPreferences`).

## 6) التفعيل — نظام UNI3 (مربوط بالجهاز)

الخدمة: `lib/services/license_service.dart`. البوابة: `features/security/activation_gate.dart`.

- **التوقيع:** Ed25519. مفتاح المالك العام المدمج:
  `W5Kc9hRB7lb9xSh/VqdR4T8GT6VaDznEwYQgXZpLZz0=`، بادئة الرسالة `UNI3`،
  ملح الجهاز `alaoufi:`.
- **رقم الجهاز:** يُشتق لكل تطبيق عبر `Base32(SHA-256(APP_ID + ":" + ANDROID_ID)[0:10])`
  (نموذج B: كل تطبيق + كل جهاز ⇒ رقم مختلف). Base32 alphabet:
  `ABCDEFGHJKLMNPQRSTUVWXYZ23456789`.
- **التحقّق:** يعرض التطبيق رقم الجهاز، ويُدخل المستخدم الكود الموقَّع من المولّد
  (keygen) المطابق لذلك الرقم. التفعيل **مربوط بالجهاز حصرًا** (لا رمز شامل).
- التفاصيل الكاملة والمعيار الإلزاميّ للمطوّرين: `LICENSING.md` + حزمة `dev-standard/`.

> **سرّ المولّد (SEED) ليس في هذا المستودع** — يوجد في تطبيق المولّد فقط، ولا
> يُنشر إطلاقًا. التطبيق يحمل المفتاح **العام** فقط.

## 7) الاشتراكات (Google Play)

الخدمة: `lib/features/subscription/subscription_service.dart`.

- **الخطط:** `sub_monthly` (شهري)، `sub_semiannual` (نصف سنوي)، `sub_annual` (سنوي).
- **التجربة:** تجربة مجانية محليّة **١٠ أيام** عند التثبيت (`trialDays = 10`) — فتح
  كامل بلا دفع، لتفادي رفض المراجعة.
- **الحالات:** `loading / entitled / expired / storeUnavailable` (enum `SubState`).
- **عند الانتهاء:** يتوقّف الاستخدام مع **الحفاظ على كل البيانات** وطلب الاشتراك.
- **التفعيل بالدفع:** تلقائيّ عبر Google Play (لا كود). الاستعادة عبر `restore()`،
  والإدارة عبر `openManage()` (تفتح اشتراكات Play). إظهار «إدارة الاشتراك» إلزاميّ.
- البوابة: `subscription_gate.dart`، وبطاقة الإعدادات: `subscription_settings_card.dart`.
- تفعَّل هذه المسارات فقط عند `kStoreBilling=true` (انظر §4).

دليل النشر ونصوص المتجر والصور: مجلّد التسليم (`نصوص_المتجر`، `privacy_policy`،
`دليل_النشر_على_قوقل_بلاي`، `store-assets/`).

## 8) مساعد الذكاء الاصطناعي

الخدمة: `lib/services/ai_service.dart`. الواجهة: `features/ai/` (الورقة + الإعدادات).
الزرّ ✨ في شريط أدوات المحرّر (id = `ai` في ترتيب الأدوات).

- **الإجراءات:** تلخيص، إعادة صياغة، تدقيق إملائيّ/لغويّ، توسيع، متابعة الكتابة،
  تعليمات مخصّصة. تعمل على النصّ المحدَّد أو كامل الملاحظة، مع
  استبدال/إدراج/نسخ للنتيجة.
- **الاتصال:** Claude Messages API عبر HTTP خام (`POST /v1/messages`)، النموذج
  الافتراضي `claude-opus-5` (قابل للتغيير من الإعدادات).
- **طريقتان (يكفي إحداهما):**
  1. **وسيط (proxy)** — الأنسب للنشر: خادم يحفظ مفتاح Anthropic سرًّا. ملف
     Cloudflare Worker جاهز: `backend/claude-proxy/worker.js` ودليله
     `backend/claude-proxy/README_AR.md`.
  2. **مفتاح خاص (BYOK)** — للاستخدام الشخصيّ: يُدخل المستخدم مفتاحه فيُخزَّن في
     التخزين الآمن على الجهاز فقط.
- كلا المسارين يرسل **نفس بنية رسائل Anthropic**؛ يختلف الرابط والترويسات فقط.

### نشر الوسيط (موجز)
1. Cloudflare → Workers → Create Worker → الصق `worker.js` → Deploy.
2. أضِف سرًّا `ANTHROPIC_API_KEY = sk-ant-…` (مشفّرًا)، و(موصى به)
   `APP_SHARED_SECRET = نصّ عشوائيّ`.
3. ضع الرابط في البناء (`AI_ENDPOINT`) أو في «إعداد المساعد» داخل التطبيق.

## 9) الأسرار والأمان (لا تُنشر)

- **مفتاح التوقيع** `alaoufi-release.jks` وكلماته (في `build.gradle.kts`): احتفظ به
  للتحديثات؛ فقدانه يمنع تحديث نفس التطبيق.
- **سرّ مولّد UNI3 (SEED):** خارج هذا المستودع تمامًا — في تطبيق المولّد فقط.
- **`ANTHROPIC_API_KEY`:** في الوسيط فقط (Cloudflare Secret) — لا في التطبيق ولا في
  مستودع عامّ. للـ BYOK يبقى على جهاز المستخدم في التخزين الآمن.
- لا تُرسِل أيّ من هذه في الحزم العامّة أو نصوص الالتزام.
